# Security policy

## Reporting a vulnerability

Please report it privately: on this repository's **Security** tab, choose **Report a vulnerability** (GitHub
private vulnerability reporting). Don't open a public issue or PR for it.

Include what is affected (plugin skill, template, factory-parent, workflow), the version or commit, and how to
reproduce it. You'll get an answer in the advisory thread; a fix is released as a new `java-pipeline-v*` or
`factory-parent-v*` version with a changelog entry.

## Supported versions

Only the newest release of each component gets fixes. Projects pin a plugin release and move by bumping it
([README](README.md#releases)).
